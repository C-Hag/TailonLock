# Playing Tailon Lock

## Starting the game

| System | Start |
|---|---|
| macOS | open `TailonLock.app`. A downloaded copy is not signed: the first time, right-click it and pick Open. |
| Linux | run `tailonlock` |
| Windows | run `TailonLock.exe` |

The game reads its data from the `assets` folder next to the program (on
macOS it is inside the app). Keep them together.

The opening film plays first. Press any key or pad button to skip it.
Then the main menu opens.

### The menus

| | Keyboard | Gamepad | Mouse |
|---|---|---|---|
| Move | arrows or W A S D | d-pad | point |
| Change a value | Left / Right | d-pad left / right | click (back: right button or wheel) |
| Press a button | Enter or Space | bottom face button, or Start | click |
| Back | Esc | right face button | BACK |

The main menu has START MISSION, HANGAR, SETTINGS, NETWORK, WATCH INTRO
and EXIT.

## Controls

### Flying (MODERN controls)

| | Player 1 | Player 2 | Gamepad |
|---|---|---|---|
| Nose down / up | W / S | Up / Down (or I / K) | left stick |
| Roll left / right | A / D | Left / Right (or J / L) | left stick |
| Throttle up / down | R / F | P / ; | right / left trigger, or right stick up / down |
| Cannon | Space | Enter | bottom face button, or right shoulder |
| Missile | Left Shift | Right Shift | right face button |
| Flares | Q | ' | left face button, or left shoulder |
| Autopilot (hold) | T | Y | right stick click |
| Look at the enemy (hold) | G (B with REALISTIC handling) | H | right stick hard left or right |
| Call the tanker (once a match) | 4 | / | |
| Gear (REALISTIC only) | G | , | d-pad down |
| Flaps (REALISTIC only) | V | . | d-pad up |

Player 2 can also use the number pad: 8 5 4 6 to fly, + and - for
throttle, 0 for the cannon, Enter for a missile and . for flares.

In 1 PLAYER both key sets fly your jet. The autopilot holds the wings
level, the height and the heading; move the stick to take over.

### Flying (CLASSIC controls)

Set CONTROLS to CLASSIC in the main menu.

| | Player 1 | Player 2 | Gamepad |
|---|---|---|---|
| Dive / climb | Q / A | P / L | left stick |
| Bank left / right | Z / X | N / M | left stick |
| Power up / down | D / S | K / J | right / left trigger |
| Fire the selected weapon | F | H | |
| Select weapon | W | O | top face button |
| Flares or chaff | R | U | left face button, or left shoulder |
| Map view | C | B | Back |
| Autopilot | T | Y | right stick click |
| Call the tanker | 4 | / | |

The weapons are C (cannon), H (heat-seeker), R (radar-guided) and S
(air-to-ground). The decoy key drops chaff when a radar missile is on you,
and flares otherwise. On a pad, the cannon and missile buttons work as in
MODERN. F1 pauses and F2 quits to the menu.

### Both sets

| Key | What it does |
|---|---|
| Tab | cockpit, chase or flyby view |
| Esc or F1 (pad: Start) | pause |
| M | sound on or off (MODERN controls) |
| F11 or Alt+Enter | full screen on or off |

### Gamepads

Pads take seats in the order they are plugged in: the first pad is
player 1, the second player 2. If a pad is unplugged during a match on one
computer, the game pauses and waits for it.

### BEAT THE DRONE!

The drone can point its nose away from its flight path. Hold the vector key
to do it: T or E for player 1, Y for player 2, and on a pad a stick click
or the top face button. Hold vector and pull for a Cobra or a flip.

### DEFEND THE CARRIER: the captain (player 2)

| Key | Pad 2 | On foot | At the tactical console | In a turret |
|---|---|---|---|---|
| Up / Down | left stick | walk | pick a turret | aim up and down |
| Left / Right | left / right stick | turn | pick a contact | aim left and right |
| P / ; | right stick | look up and down | P launches a jet | |
| ' | right shoulder | run | turret on AUTO or HOLD | |
| Enter | bottom face button | use what is in front of you | order the turret onto the contact | fire |
| Right Shift | right face button | | step back | step back |

## Game modes

| MODE | What it is |
|---|---|
| 1 PLAYER | you against the CPU |
| 2 PLAYERS | split screen: VERSUS (player 1 against player 2) or CO-OP (both against the CPU) |
| DEFEND THE CARRIER | player 1 flies from the carrier against five waves of strike jets. CREW: PILOT + COMMANDER (player 2 runs the carrier) or PILOT ONLY (the turrets fire on their own). |
| BEAT THE DRONE! | one jet against the DR-7 Vesper drone. THE DRONE: CPU FLIES IT or PLAYER 2 FLIES IT. |

With CARRIER VS BASE, go to full power on the catapult and it fires. On a

### The jets

AF-40 Nightshade, LF-27 Bobcat, ECF-90 Sirocco, JA 46 Gladan,
SY-26 Tianlong, Vk-33 Strizh, Ks-55 Grifon, NF-24 Cormorant.

### The hangar

HANGAR shows the chosen jet with its role and scores. Left and Right change
the jet; Enter takes it. Arm it here:

- HEAT-SEEKERS, RADAR-GUIDED, AIR-TO-GROUND: up to 8 missiles in all.
  At most 6 radar-guided and 2 air-to-ground, and no radar-guided missiles
  with air-to-ground ones.
- MORE FLIGHT INFO opens the jet's full sheet.
- START MISSION starts the match; DONE goes back.

In 2 PLAYERS the SEAT row picks whose jet you set.

## Network play

NETWORK in the main menu plays a match between two computers, one player
on each. Each player flies with the player 1 keys and the full screen.
The host's main menu sets the map, time, weather and rules. Each player's
jet and arming are player 1's in their own hangar.

### The NETWORK page

| Row | What to set |
|---|---|
| I WANT TO | HOST A GAME or JOIN A GAME |
| MATCH (host) | VERSUS, CO-OP, DRONE: GUEST FLIES IT, DRONE: YOU FLY IT |
| OVER | LAN, INTERNET ADDRESS or INTERNET RELAY |
| GAME (join, LAN) | the game picked from the list of games found |
| HOST ADDRESS (join, address) | the host's address |
| RELAY SERVER (relay) | the relay's address |
| GAME CODE (join) | the host's 6 digits |
| YOUR NAME | your pilot name |

Then press HOST GAME or JOIN. CANCEL stops it.

### Hosting

1. Set the match in the main menu, then open NETWORK.
2. Set I WANT TO to HOST A GAME, pick the MATCH and how (OVER).
3. Press HOST GAME. The screen shows a 6-digit GAME CODE. Give it to your
   friend and nobody else.

- **LAN**: players on your network find your game in their list.
- **INTERNET ADDRESS**: forward UDP port 27960 on your router to this
  computer. Give your friend your public address and the code.
- **INTERNET RELAY**: no port forwarding. Type the RELAY SERVER. Both
  computers connect to it.

### Joining

1. Open NETWORK and set I WANT TO to JOIN A GAME.
2. Pick OVER:
   - **LAN**: pick the game under GAME and type the code.
   - **INTERNET ADDRESS**: type the HOST ADDRESS, like `192.0.2.10` or
     `192.0.2.10:27960`, and the code.
   - **INTERNET RELAY**: type the RELAY SERVER and the code.
3. Press JOIN.

A wrong code is refused. After 10 wrong codes the host stops; host again
for a new code.

### The relay server

The relay is a small server program, `tl_relay`, built with the game
(not on Windows). Run it on a computer with UDP port 27970 open. It only
passes on encrypted packets. It does see the game code, so use a relay you
trust.

### During and after a match

- Pause does not stop a network match.
- If nothing arrives for 6 seconds, the match ends with CONNECTION LOST.
- After a match the host picks REMATCH or MAIN MENU.
- On Windows, allow the game through the firewall the first time it hosts.

## Settings

SETTINGS in the main menu. The game saves every change by itself.

| Row | Choices |
|---|---|
| G EFFECTS | BLACKOUT ON (grey-out and blackout above about 7 g, red-out below about -2.5 g) or ARCADE (none) |
| RENDERER | MODERN (GPU) or RETRO (software). A change needs a restart. |
| GRAPHICS | LOW, MEDIUM, HIGH, ULTRA (MODERN only) |
| INVERT PITCH | ON or OFF |
| SOUND | ON or OFF |
| VOLUME | 1 to 10 |
| HEARING | ADULT or CHILD (CHILD caps the volume at 5) |
| MUSIC | ON or OFF |
| THEME | FULL BURN, GHOST SQUADRON, STEEL HORIZON |
| INTRO AT START | ON or OFF |

The settings file is `settings.ini`, in `~/.config/tailonlock` on Linux,
`%APPDATA%\TailonLock` on Windows and
`~/Library/Application Support/TailonLock` on macOS.

After every hour of sound, the menu and the pause screen ask you to rest
your ears for a few minutes.

## System requirements

| | Minimum |
|---|---|
| System | 64-bit Windows 10 or 11, Linux, or macOS 11 or later |
| CPU | any dual-core; x86-64 (Windows, Linux) or arm64 / x86_64 (macOS) |
| Memory | 1 GB |
| Disk | 20 MB |
| Graphics | a GPU for the MODERN renderer; without one, RETRO runs on the CPU |
| Network play | 64 kbit/s each way |

For HIGH or ULTRA at 1080p and 60 fps: a quad-core CPU, 4 GB of memory and
a GPU with 2 GB of memory.
